# FinFlow - Digital Loan Processing Platform

## Overview

FinFlow is a microservices-based digital loan processing platform built using Java and Spring Boot.

The platform demonstrates enterprise-level architecture including service discovery, API gateway, centralized configuration, authentication, event-driven communication, and containerized deployment.

## Planned Architecture

- API Gateway
- Eureka Discovery Server
- Config Server
- Auth Service
- User Service
- Loan Service
- Credit Service
- Document Service
- Payment Service
- Notification Service

## Technology Stack

- Java 17
- Spring Boot
- Spring Cloud
- Spring Security
- JWT
- MySQL
- Kafka
- Redis
- Docker
- Maven
- GitHub
